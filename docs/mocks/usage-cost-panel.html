Usage & cost

What your agents spend across models, features and tools. Local models are free and only count tokens.

Measure
How costs are counted
  • Every model request records usage on the assistant message. Cost is the provider-reported usage.cost when present (OpenRouter), otherwise tokens × the model's price per 1M (input, cached input, output).
  • Tool cost = the request that read a tool's result back into the model. The tool result's tokens are the main driver.
  • Feature cost = requests that consumed that feature's tool output, plus requests the feature makes on its own (Auto Compact summaries). Base chat = turns before any tool ran.
  • Local runners (WebLLM, Wllama, Transformers.js, Ollama, LM Studio) cost $0 and count tokens only.
  • Not counted yet: background memory and knowledge extraction calls.
